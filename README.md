# PixDivide

Crop one part of an image or split it into multiple independently adjustable parts. Static app for GitHub Pages with automatic and manual grid selection.

## GitHub Pages
Upload these files to the repository root, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

All image processing happens locally in the browser.

The interface is available in Serbian, English, German and Spanish. On first use it follows the first supported language in the browser's language preference list (`navigator.languages`), falling back to English. The language menu in the header overrides this choice and remembers it in local storage on that device. Changing language does not change image pixels or export settings.

Upload an image, adjust any of the independent scene rectangles, and choose Original or a square 2048, 3072, or 4096 px export. Target size and PNG/JPEG format are shared export settings whether AI is enabled or not. “Prikaži deo” shows the selected crop without AI at the chosen export dimensions and format; its full-size link opens those exact pixels in a new tab. With AI enabled and Original size selected, this plain preview is interpolated to the same 2× dimensions as the AI export. Preview and ZIP use each scene's current crop. Square export preserves the full crop without stretching by adding white margins when needed. Upscaling interpolates pixels and cannot recover missing source detail.

Double-click a scene in the main preview, or double-tap it on a phone, to select and focus it. While focus is active, a click on another scene focuses that scene. Double-click the focused scene again, or press “Ukloni fokus”, to restore the zoom and position from before focus. When the whole source image fits inside the viewer, drag inside a scene to move its crop without changing its size; dragging an edge still resizes it. When the image extends outside the viewer, dragging pans the view instead. “Istakni ivice” dims the selected scene and hides its yellow and green handles so the outline is easier to inspect. Click again to restore the editing view. This preview effect follows selection and is not exported. The preview includes padding around the source image so outer-edge handles remain visible. Toggle “Prikaži sve granice” to show the other scenes in white without resize handles. To align the selected scene, choose a reference scene and Top, Bottom, Left or Right; the matching coordinate is copied to the selected scene only. Alignments that would cross its opposite edge are rejected.

Run `node verify.js` for crop, focus, alignment, export and service-worker checks.

Enter original-pixel width and height and use “Primeni dimenzije” to resize the selected crop. Choose an aspect preset or a custom positive width:height and use “Primeni odnos” to lock it for that scene. The lock is maintained during dragging and dimension changes. Locked alignment translates the whole crop. Applying “Slobodno” unlocks the aspect ratio. Resizing keeps the top-left position when possible and shifts the crop inside the source image if necessary; invalid or oversized dimensions are rejected.

Every yellow handle has a scene number at 55% text opacity; the handle remains opaque. Alternating pale green/blue arrow handles placed inside each scene between the resize handles copy that edge from the adjacent grid scene: left/right arrows on horizontal edges and up/down arrows on vertical edges. Directions without a neighbour are omitted. Click an arrow to align; dragging, cancellation, and pinch gestures do not trigger alignment. On screens at least 1000 px wide the controls sit to the right of the canvas; narrower screens retain the controls above it.

The all-boundaries overview uses pale-yellow outlines, hides yellow resize handles, and disables resizing, manual dimensions and aspect changes. Arrow clicks align a scene while retaining overview; clicking a scene returns to single-scene editing. Panning, pinching and cancelled clicks keep overview open.


## Local AI export

AI enhancement uses UpscalerJS 1.0.0 with TensorFlow.js 4.11.0 for ESRGAN/Real-ESRGAN and ONNX Runtime Web 1.30.0 for SwinIR. Runtime scripts and all model files are committed in `vendor/`. No image is uploaded and no third-party inference API or CDN is contacted. Static assets download from this site's own origin on first use; the service worker caches successful requests for offline reuse. An unused model still needs its first online download.

Choose whether AI processing is enabled, one target size (Original, 2048, 3072 or 4096 px square), and PNG/JPEG. The target size controls both AI processing and export. The model menu offers local ESRGAN Slim and Medium (2×/4×), ESRGAN Thick (2×/4×/8×), Real-ESRGAN general (4×), Real-ESRGAN anime (4×), and experimental SwinIR (8×). Automatic selection uses Slim and smaller patches on mobile/low-memory devices. Thick and Real-ESRGAN are marked demanding; SwinIR is experimental and not adapted to phones. Real-ESRGAN processes overlapping 64×64 tiles; SwinIR processes overlapping 32×32 tiles through local ONNX Runtime Web WASM. SwinIR loads about 51 MB of model weights and about 28 MB of WASM runtime on first use, and a large crop can take a long time. AI runs on original cropped pixels in a dedicated Web Worker. TensorFlow models use WebGL/OffscreenCanvas when supported and a local CPU fallback; SwinIR uses local WASM. The app chooses the needed ESRGAN model scale according to the target, falling back to a smaller ESRGAN scale when the result exceeds device limits. Real-ESRGAN uses 4× only and SwinIR uses 8× only; both report an error when their result exceeds the limit. It interpolates the remainder if the model output is smaller than the target. When the crop is already large enough for the selected square target, it uses the original pixels without AI. With Original selected, ESRGAN uses 2×, Real-ESRGAN 4× and SwinIR 8×. With AI switched off, ordinary canvas scaling is used; it does not reconstruct missing detail. ZIP scenes are processed sequentially. PNG is the default lossless output; JPEG uses quality 0.98. Single-scene downloads, ZIP and comparison use the same settings.

With **Original** output size, enabled AI preserves the crop's aspect and exports at 2× with ESRGAN, 4× with Real-ESRGAN, or 8× with SwinIR. Square output sizes fit the enhanced crop without stretching and add white margins as before. Choosing a square larger than the AI result involves further ordinary interpolation; the comparison identifies that case. AI estimates details and may alter textures, including text; it cannot guarantee print quality or exact lettering. Use **Uporedi AI rezultat** to inspect the selected crop at the chosen output size and PNG/JPEG format before printing. Both comparison images use that format and output size, including white margins. The AI side is the exact encoded image downloaded from the comparison. The comparison fits the screen without enlarging beyond the generated image dimensions. Existing grid thumbnails continue to preview original crop boundaries.

Comparison and exports show a full-screen progress overlay that blocks the controls until completion or cancellation. **Prekini** terminates the worker and suppresses the download; an interrupted ZIP is never downloaded partially. Retry starts a fresh worker. AI model output is limited to about 8 million pixels on mobile/low-memory devices and 16 million on desktop. A 4096 px square output contains about 16 million pixels. Oversized AI requests show an error in the processing panel. If processing fails, try a smaller crop or switch AI off. CPU performance and mobile GPU support vary; no target-device benchmark has been performed. SwinIR 8× and ESRGAN Thick 8× are experimental and may fail or take a long time on large crops; actual iPhone Safari behavior has not been tested.

The committed vendor files let GitHub Pages serve this repository without a build. To reproduce runtime files and ESRGAN models: `npm ci`, then `npm run vendor:ai`. Dependencies and versions are pinned in `package-lock.json`; Real-ESRGAN browser graph files come from a pinned [web-realesrgan commit](https://github.com/Aaaou/-web-realesrgan/tree/7a5c9f0a82643f7ae4ba4967c039ea03f630a90c) and are checksum verified by `scripts/vendor-real-ai.js`. SwinIR was exported from the [official repository at commit 6545850](https://github.com/JingyunLiang/SwinIR/tree/6545850fbf8df298df73d81f3e8cba638787c8bd) and its `001_classicalSR_DF2K_s64w8_SwinIR-M_x8.pth` release weights (SHA-256 `6b522c1ea5c21006ce3398797eb20b131ca0024cc6e7b8f3d5d29fad1310a49c`) using `scripts/export-swinir.py` and a fixed 32×32 input. The committed ONNX model is checksum checked during tests. Third-party licenses are in `vendor/licenses/`; TensorFlow.js and SwinIR are Apache-2.0, ONNX Runtime Web and UpscalerJS/model packages are MIT, and the converted Real-ESRGAN graph files are distributed with the source repository's GPL-2.0 license.

Run `npm test` for geometry/export checks, worker cancellation/device-profile checks, service-worker offline caching, and real inference of the nine TensorFlow models and SwinIR through local WASM. The TensorFlow inference test starts a temporary loopback server and rejects external fetches. Browser worker inference was also checked with Chromium using one tile and multiple tiles. These tests validate operation and output dimensions, not visual improvement or iPhone Safari behavior.

## Grid detection

Automatic mode estimates rows and columns independently from bright or dark gutters spanning the image. It supports rectangular and unevenly spaced grids and excludes detected gutters from crops. Analysis uses a preview up to 1200 pixels; exports retain original image pixels. This is a gutter heuristic, not semantic scene recognition: merged cells, overlapping collages and images without clear separators may need manual selection. With no detected separators the image stays as one scene.

Choose Ručno, enter 1–12 columns and rows, then Primeni mrežu. Manual mode refines equal divisions to nearby detected gutters, otherwise uses equal cells. Reapplying detection or changing the grid resets crop adjustments and aspect locks. Navigation, neighbor alignment and ZIP export use the resulting scene count.

## Interface

The light interface follows `ui.png`: a large image canvas with the scene gallery below it, and a desktop sidebar with grid, crop, zoom, processing and export controls. On smaller screens the canvas and controls stack vertically. The preview fits within the viewport height while exports retain their original dimensions. Drop an image up to 50 MB on the canvas or use its initial image button. Once loaded, a button below the canvas removes it and clears crops, focus, the gallery and pending image loads. Privacy and usage help are available from the header; extra alignment controls are under Poravnanje i pomoć.

Prikaži deo opens the crop resized to the selected export dimensions and format in a floating preview, without AI enhancement. Uporedi AI rezultat opens a before/after slider with the selected export size and format; use the slider, Original or AI rezultat, then download the enhanced image shown. A dark backdrop blocks the main view; click it, press Escape, or use the close button to dismiss the preview. The full-size button opens the version named on the button in a new tab at its actual pixel dimensions. The AI toggle remembers the previous magnification. The gallery stays below the canvas; its heading folds or unfolds the scene cards.
